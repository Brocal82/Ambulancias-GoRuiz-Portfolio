# Security Documentation

This folder is the canonical security reference for the project.

## Read order

1. `architecture.md` - controls and design decisions
2. `operations.md` - how to run and monitor controls in production
3. `incident-response.md` - what to do during a potential data leak
4. `governance.md` - monthly review and continuous-improvement checklist

## Scope covered

- Superadmin access model and break-glass controls
- Tenant isolation gate and branch enforcement
- Persistent audit logging and retention
- Monitoring metrics and alert interpretation
- Incident runbook and tabletop execution
