## ¿Qué manual leer?

| Rol | Empieza aquí |
|-----|----------------|
| **Administrador** (panel web) | `/<idioma>/admin/README.md` |
| **Trabajador** (app móvil o web worker) | `/<idioma>/worker/README.md` |

Los administradores también deben consultar las guías de **trabajador** para formar al equipo y resolver incidencias del día a día.

---

## Módulos y disponibilidad

Cada empresa tiene activos solo los módulos contratados (`enabledModules`). Si no ves un menú o una pantalla descrita en estas guías, contacta con el superadministrador de GoRuiz o con tu responsable interno.
