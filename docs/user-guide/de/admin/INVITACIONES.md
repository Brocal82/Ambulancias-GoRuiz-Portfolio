# Einladungen (Administrator)

**Route:** `/admin/invitations`

---

## Wofür es dient

Ermöglicht es einem **neuen Mitarbeiter** (oder einer anderen Unternehmensrolle), sein Konto anzulegen, ohne dass der Administrator das Passwort für ihn festlegt.

---

## Einladung erstellen

1. Gehen Sie zu **Einladungen**.
2. Klicken Sie auf Erstellen / neue Einladung.
3. Geben Sie die **E-Mail** des Empfängers an (und weitere vom Formular verlangte Daten).
4. Speichern und **Link kopieren** oder per E-Mail senden.

---

## Was der Eingeladene tut

1. Öffnet den Link (`/invitation/accept`).
2. Füllt das Registrierungsformular aus (Name, Passwort usw.).
3. Meldet sich mit seinen Zugangsdaten an.
4. Auf dem Handy: GoRuiz-App installieren und mit derselben E-Mail anmelden.

Anleitung: [App-Einstieg](../worker/INICIO.md).

---

## Häufige Probleme

| Problem | Lösung |
|---------|--------|
| Link abgelaufen oder bereits verwendet | Neue Einladung erstellen |
| „E-Mail bereits registriert“ | Benutzer existiert bereits; Zugangswiederherstellung nutzen oder unter Benutzer prüfen |
| E-Mail kommt nicht an | Spam prüfen; Link manuell erneut senden |
