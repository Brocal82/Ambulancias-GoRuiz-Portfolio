# Nachrichten (Administrator)

**Routen:** `/admin/messages`, `/admin/messages/sent`  
**Modul:** Nachrichten (in der Regel immer verfügbar)

---

## Nachrichten senden

1. Öffnen Sie **Nachrichten**.
2. Verfassen Sie Betreff und Text.
3. Wählen Sie **Empfänger** (Mitarbeiter oder Gruppen je nach Ansicht).
4. Optional: Dateien anhängen (Bilder oder PDF je nach Limits).
5. Senden.

Mitarbeiter erhalten die Nachricht in der App (Register **Nachrichten**) und ggf. eine **Push-Benachrichtigung**, wenn die App installiert ist.

Mitarbeiter-Anleitung: [Nachrichten](../worker/MENSAJES.md).

---

## Posteingang und Gesendet

- **Empfangen:** Nachrichten, die Ihnen andere gesendet haben (falls für Admins relevant).
- **Gesendet** (`/admin/messages/sent`): Verlauf ausgehender Mitteilungen.

---

## Anhänge

Anhänge sind keine öffentlichen Links. Sie werden sicher innerhalb der Anwendung geöffnet.

---

## Empfehlungen

- Verwenden Sie klare Betreffzeilen.
- Bei dringenden Hinweisen (Dienständerung) kombinieren Sie die Nachricht bei kritischen Fällen mit mündlicher Bestätigung.
- Datenschutz beachten: keine sensiblen medizinischen Daten per Nachricht senden, wenn sie über das Krankmeldungs-Modul gehören.
