# Excel-Planung (Administrator)

**Route:** `/admin/excel-planning`  
**Erforderliches Modul:** `excel-planning`

---

## Wann nutzen

Wenn Ihr Unternehmen die Wochenplanung aus einer **Excel-Tabelle** statt (oder zusätzlich zu) manuellen Dienst-Vorlagen importiert.

---

## Typischer Ablauf

1. Excel gemäß Vorlage oder Format von GoRuiz vorbereiten.
2. **Excel-Planung** öffnen.
3. Datei **importieren**.
4. Hinweise oder Parse-Fehler prüfen (übersprungene Zeilen, unbekannte Spalten).
5. Woche **veröffentlichen**, wenn die Vorschau stimmt.
6. Mitarbeiter sehen die aktualisierte Agenda in der App.

---

## Grenzen

- Nur Excel-Dateien (`.xlsx`, `.xls`) innerhalb der erlaubten Größe.
- Import-Limit pro Zeitraum; bei Fehler warten und erneut versuchen.

---

## Bezug zu klassischer Dienstplanung

Wenn Sie auch [Dienste](./TURNOS.md) per Vorlagen nutzen, vermeiden Sie zwei unkoordinierte Quellen für dieselbe Woche.
