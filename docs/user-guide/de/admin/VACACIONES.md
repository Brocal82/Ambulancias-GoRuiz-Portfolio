# Urlaub (Administrator)

**Route:** `/admin/vacations`  
**Erforderliches Modul:** `vacation`

---

## Was Sie tun können

- **Ausstehende Anträge** der Mitarbeiter einsehen.
- Angefragte Daten **genehmigen** oder **ablehnen**.
- **Gegenvorschlag** für Daten senden (der Mitarbeiter kann annehmen oder stornieren).
- Teamkalender / Verfügbarkeit einsehen (je nach aktiven Ansichten).

---

## Typischer Ablauf

1. Der Mitarbeiter beantragt Urlaub in der App → [Urlaub Mitarbeiter](../worker/VACACIONES.md).
2. Sie erhalten den Antrag im Status **ausstehend**.
3. Prüfen Sie Überschneidungen mit Diensten und anderen Urlaubs-/Krankmeldungen.
4. Genehmigen, ablehnen oder schlagen Sie andere Daten vor.
5. Der Mitarbeiter erhält das Ergebnis in der App (ggf. mit Push-Benachrichtigung).

---

## Empfehlungen

- Antworten Sie zeitnah, damit Mitarbeiter planen können.
- Bei alternativen Daten geben Sie eine **Notiz** oder Begründung im vorgesehenen Feld an.
- Nach Genehmigung prüfen Sie, ob die **Dienstplanung** den Mitarbeiter an diesen Tagen noch zuweist (ggf. unter [Dienste](./TURNOS.md) anpassen).
