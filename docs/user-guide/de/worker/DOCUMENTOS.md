# Dokumente (Mitarbeiter)

**Zugang:** über Start oder Bereich Dokumente  
**Modul:** `documents`

---

## Was das sind

Dokumente, die Ihr Unternehmen Ihnen **zustellt**: Rundschreiben, Protokolle, Formulare usw.

---

## So nutzen Sie sie

1. **Dokumente** öffnen.
2. Sie sehen nur, was Ihnen zugesandt wurde.
3. Jedes Dokument öffnen zum Lesen (PDF oder anderes erlaubtes Format).
4. Falls **Lesebestätigung** verlangt wird, der angezeigten Aktion folgen.

Admin-Anleitung: [Dokumente Admin](../admin/DOCUMENTOS.md).

---
