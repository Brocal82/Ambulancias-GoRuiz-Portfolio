# App-Einstieg (Mitarbeiter)

## App installieren

1. Laden Sie **Ambulancias GoRuiz** aus dem Store herunter, den Ihr Unternehmen angibt (iOS / Android).
2. Öffnen Sie die App.

---

## Erster Zugang

1. Wenn Sie einen **Einladungslink** erhalten haben, öffnen Sie ihn zuerst im Browser, schließen Sie die Registrierung ab und melden Sie sich dann in der App mit derselben E-Mail und demselben Passwort an.
2. Geben Sie auf dem **Anmeldebildschirm** E-Mail und Passwort ein.
3. Bei erfolgreicher Anmeldung sehen Sie **Start** mit Zugängen zu den Bereichen.

**Hinweis:** Administratorenkonten können die Mitarbeiter-App nicht nutzen; Sie erhalten eine Sperrmeldung.

---

## Untere Register (üblich)

| Register | Funktion |
|----------|----------|
| **Start** | Schnellzugriffe (Dokumente, Prämien usw.) |
| **Agenda** | Ihre Dienste |
| **Arbeitstag** | Tag erfassen (falls Modul aktiv) |
| **Nachrichten** | Mitteilungen (ggf. Badge für Ungelesenes) |
| **Profil** | Ihre Daten und Abmeldung |

Weitere Register (Urlaub, Krankmeldung, Termine) können je nach aktiven Modulen oder über Start erscheinen.

---

## Sprache

Bei mehrsprachigem Unternehmen folgt die Sprache ggf. der des Geräts oder der Web-Konfiguration. Anleitungen gibt es auf Spanisch, Deutsch und Englisch unter `docs/user-guide/`.

---

## Benachrichtigungen

Beim ersten Start kann die App um **Benachrichtigungen** bitten. Akzeptieren Sie, wenn Sie Hinweise zu neuen Nachrichten oder anderen Unternehmensmitteilungen wünschen.

---

## Abmelden

**Profil** → Abmelden. Melden Sie sich erneut an, wenn Sie das Gerät wechseln oder das Telefon teilen.

---

## Häufige Probleme

| Problem | Was tun |
|---------|---------|
| Falsches Passwort | Groß-/Kleinschreibung prüfen; Reset beim Admin anfragen |
| Keine Dienste in der Agenda | Admin muss Woche erstellen und Sie zuweisen |
| Sitzung abgelaufen | Erneut anmelden |
| „Administratorenkonto“ | Web-Panel nutzen, nicht die Mitarbeiter-App |
