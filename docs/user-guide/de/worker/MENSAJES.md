# Nachrichten (Mitarbeiter)

**Register:** Nachrichten

---

## Nachrichten empfangen

- Mitteilungen Ihres Unternehmens erscheinen in der Liste.
- Das **Badge** am Register zeigt Ungelesenes (ggf. auch Push-Benachrichtigung).
- Nachricht öffnen für den vollständigen Text.

---

## Anhänge

Bei Anhängen aus der App öffnen. Download erfolgt sicher (keine öffentlichen Links).

---

## Nachrichten senden

Falls erlaubt, können Sie Nachrichten an angegebene Empfänger verfassen. Halten Sie interne Kommunikationsregeln ein.

Admin-Anleitung: [Nachrichten Admin](../admin/MENSAJES.md).

---

## Benachrichtigungen

Im Hintergrund kann eine neue Nachricht eine Benachrichtigung anzeigen. Beim Tippen gelangen Sie meist direkt zu **Nachrichten**.
