# Prämien (Mitarbeiter)

**Zugang:** über Start oder Bereich Prämien  
**Modul:** `praemien`

---

## Was Sie sehen

- Übersicht der **Prämien** für Monate, die Ihr Unternehmen **bestätigt** oder **bezahlt** hat.
- Im automatischen Modus hängen sie von erfassten und vom Admin geprüften Arbeitstagen ab.
- Im manuellen Modus trägt der Admin die Beträge ein.

Admin-Anleitung: [Prämien Admin](../admin/PRIMAS.md).

---

## Wenn eine Prämie fehlt

- Der Monat kann noch im Entwurf sein.
- Arbeitstage sind ggf. noch nicht geprüft.
- Das Modul ist ggf. nicht aktiv.

Fragen Sie Ihren Administrator mit dem konkreten Monat.
