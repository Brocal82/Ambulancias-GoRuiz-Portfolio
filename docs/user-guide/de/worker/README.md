# Mitarbeiterhandbuch

Nutzung der **GoRuiz-Mobile-App** (empfohlen) und, falls Ihr Unternehmen es erlaubt, Web-Routen unter `/worker`.

Dieses Handbuch ist nur für Benutzer mit der Rolle **Mitarbeiter** (`worker`). Wenn Sie Administrator sind, lesen Sie auch das [Administratorhandbuch](../admin/README.md).

## Module, die Sie nicht sehen

Fehlt ein Register (z. B. Arbeitstag oder Urlaub), hat Ihr Unternehmen das Modul ggf. nicht aktiv. Fragen Sie Ihren Administrator.

---

## Hilfe von der Verwaltung

Ihr Vorgesetzter nutzt die Admin-Anleitungen für Urlaubsgenehmigung, Lohnabrechnungs-Upload usw. Sie können ihm bei Bedarf das [Admin-Handbuch](../admin/README.md) nennen.
