# Störung melden (Mitarbeiter)

**Zugang:** über Start oder Ablauf im Arbeitstag (je nach Version)  
**Web-Entsprechung:** `/worker/report-issue`

---

## Wann nutzen

Wenn Sie während des Dienstes ein Problem an einer **Ambulanz** oder Ausrüstung feststellen (mechanischer Defekt, Mangel usw.).

---

## So melden Sie

1. **Störung melden** (oder gleichwertige Option) öffnen.
2. Problem klar beschreiben.
3. **Ambulanz** angeben, falls das Formular es verlangt.
4. Optional: **Foto** anhängen (nur Bilder auf öffentlichen Routen; sensible Dokumente je nach Ansicht).
5. Senden.

**Administrator** und Mechanik-Team sehen die Meldung im Panel → [Mechanik Admin](../admin/MECANICA.md).

---

## Sendelimit

Es gibt ein Limit pro Minute gegen Spam. Bei Fehler kurz warten und erneut versuchen.
