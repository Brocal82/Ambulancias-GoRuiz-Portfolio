# Urlaub (Mitarbeiter)

**Bereich:** Urlaub (Register oder Zugang über Start)  
**Modul:** `vacation`

---

## Urlaub beantragen

1. **Urlaub** öffnen.
2. **Startdatum** und **Enddatum** wählen.
3. Antrag senden.
4. Status **ausstehend**, bis der Admin antwortet.

---

## Antwort des Administrators

Möglich sind:

- **Genehmigt** — Daten bestätigt.
- **Abgelehnt** — Grund beim Vorgesetzten erfragen.
- **Alternativvorschlag** — Admin schlägt andere Daten vor; Sie **nehmen an** oder **brechen ab**.

Admin-Anleitung: [Urlaub Admin](../admin/VACACIONES.md).

---

## Tipps

- Beantragen Sie rechtzeitig im Voraus.
- Prüfen Sie die **Agenda** nach Genehmigung, falls noch Dienste entfernt werden müssen.
