# Appointments (admin)

**Route:** `/admin/appointments`  
**Required module:** `appointments`

---

## What you can do

- View workers' **appointment requests**.
- **Propose available time slots**.
- Confirm or cancel appointments.
- Manage the company's appointment calendar.

---

## Typical workflow

1. Worker requests an appointment from the app → [Worker appointments](../worker/CITAS.md).
2. Admin receives the request.
3. Admin proposes one or more time slots.
4. Worker accepts a slot or cancels.

---

## Tips

- Propose realistic time slots to reduce back-and-forth.
- Use internal notes if the screen allows (medical review, meeting, etc.).
