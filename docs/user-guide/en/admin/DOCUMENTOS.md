# Company documents (admin)

**Route:** documents module in the admin panel (depending on your company menu)  
**Required module:** `documents`

---

## What you can do

- **Upload** documents (PDF, etc.) with title and description.
- **Deliver** each document to one or more workers.
- See who has **received** or **acknowledged** reading (if the workflow includes confirmation).
- **Delete** obsolete documents (they are no longer available).

---

## Recommended workflow

1. Upload the document (internal policy, circular, form).
2. Select target workers → **Deliver**.
3. Workers see it under **Documents** in the app.
4. Optional: request read confirmation per internal rules.

Worker guide: [Documents](../worker/DOCUMENTOS.md).

---

## Limits

- Maximum file size per server configuration (usually 10 MB for PDF).
- **Upload limit per time period** to prevent abuse; if it fails, wait a few minutes and try again.

---

## Best practices

- Descriptive titles ("Protocol X — 2026").
- Deliver only to those who should see the document.
- For payroll use the [Payroll](./NOMINAS.md) module, not generic documents.
