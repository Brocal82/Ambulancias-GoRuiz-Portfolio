# Invitations (admin)

**Route:** `/admin/invitations`

---

## What it is for

Allows a **new worker** (or other company role) to create their account without the admin setting the password for them.

---

## Create an invitation

1. Go to **Invitations**.
2. Click create / new invitation.
3. Enter the recipient's **email** (and any other data the form requires).
4. Save and **copy the invitation link** or send it by email.

---

## What the invitee does

1. Opens the link (`/invitation/accept`).
2. Completes the registration form (name, password, etc.).
3. Signs in with their credentials.
4. On mobile: install the GoRuiz app and sign in with the same email.

Guide: [Getting started in the app](../worker/INICIO.md).

---

## Common issues

| Issue | Solution |
|-------|----------|
| Link expired or already used | Create a new invitation |
| "Email already registered" | User already exists; use password recovery or check under Users |
| Email not received | Check spam; resend the link manually |
