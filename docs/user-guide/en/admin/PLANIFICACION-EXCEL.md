# Excel planning (admin)

**Route:** `/admin/excel-planning`  
**Required module:** `excel-planning`

---

## When to use it

If your company imports the weekly schedule from an **Excel sheet** instead of (or in addition to) manual shift templates.

---

## Typical workflow

1. Prepare the Excel file per the template or format agreed with GoRuiz.
2. Open **Excel planning**.
3. **Import** the file.
4. Review warnings or parse errors (skipped rows, unknown columns).
5. **Publish** the week when the preview is correct.
6. Workers see the updated schedule in the app.

---

## Limits

- Excel files only (`.xlsx`, `.xls`) within the allowed size.
- Import limit per time period; if it fails, wait and try again.

---

## Relationship with classic shifts

If you also use [Shifts](./TURNOS.md) via templates, avoid publishing two uncoordinated sources for the same week.
