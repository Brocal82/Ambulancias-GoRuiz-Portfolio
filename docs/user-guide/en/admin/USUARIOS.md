# Users and workers (admin)

**Routes:** `/admin/users`, `/admin/user/:userId`  
**Module:** always available (company user management)

---

## User list

Under **Users** you see your company's staff: name, role, status, contact details.

---

## Worker profile

When opening a user (`/admin/user/:userId`) you can:

- View and edit profile data (depending on permissions).
- Manage **P-Schein** (document and expiry date) if relevant to your operations.
- Upload documentation linked to the worker.
- Review ambulance role (driver, medic, both) if you use role-based scheduling.

---

## Deactivate a user

If a worker leaves the company, **deactivate** them instead of deleting when possible. An inactive user:

- Cannot sign in.
- Is excluded from recommended future assignments.

---

## Relationship with invitations

New users usually join via [Invitation](./INVITACIONES.md). The user list shows who has completed registration.
