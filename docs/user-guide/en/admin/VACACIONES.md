# Vacation (admin)

**Route:** `/admin/vacations`  
**Required module:** `vacation`

---

## What you can do

- View workers' **pending requests**.
- **Accept** or **reject** requested dates.
- Send a **counterproposal** of dates (the worker can accept or cancel).
- Check team calendar / availability (depending on active screens).

---

## Typical workflow

1. The worker requests vacation from the app → [Worker vacation](../worker/VACACIONES.md).
2. You receive the request in **pending** status.
3. Review overlaps with shifts and other leave/vacation.
4. Accept, reject, or propose other dates.
5. The worker receives the result in the app (and may get a push notification).

---

## Best practices

- Respond within a reasonable time so workers can plan.
- If you propose alternative dates, add a **note** or reason in the provided field.
- After approval, check that **shift scheduling** is no longer assigning the worker on those days (adjust in [Shifts](./TURNOS.md) if needed).
