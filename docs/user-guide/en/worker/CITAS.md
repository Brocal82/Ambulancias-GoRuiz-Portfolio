# Appointments (worker)

**Section:** Appointments  
**Module:** `appointments`

---

## Request an appointment

1. Open **Appointments**.
2. Create a new request with the reason or type indicated on the form.
3. Wait for the administrator's response.

---

## Response

The admin may **propose time slots**. Choose the one that suits you or cancel if you no longer need it.

Admin guide: [Admin appointments](../admin/CITAS.md).

---

## Reminders

If you receive a push notification with an appointments link, tap it to open the section.
