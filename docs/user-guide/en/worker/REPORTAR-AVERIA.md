# Report breakdown (worker)

**Access:** from Home or workday flow (depending on version)  
**Web equivalent:** `/worker/report-issue`

---

## When to use it

If you notice a problem with an **ambulance** or equipment during service (mechanical fault, defect, etc.).

---

## How to report

1. Open **Report breakdown** (or the equivalent option).
2. Describe the problem clearly.
3. Indicate the affected **ambulance** if the form asks for it.
4. Optional: attach a **photo** (images only on public routes; sensitive documents depending on screen).
5. Submit.

The **administrator** and mechanics team will see it in the panel → [Admin mechanics](../admin/MECANICA.md).

---

## Submission limit

There is a reports-per-minute limit to prevent spam. If submission fails, wait a moment and try again.
