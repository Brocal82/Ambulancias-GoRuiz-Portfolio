# Vacation (worker)

**Section:** Vacation (tab or access from Home)  
**Module:** `vacation`

---

## Request vacation

1. Open **Vacation**.
2. Choose **start date** and **end date**.
3. Submit the request.
4. Status **pending** until the admin responds.

---

## Administrator response

Possible outcomes:

- **Accepted** — dates approved.
- **Rejected** — ask your manager for the reason.
- **Alternative option** — admin proposes other dates; you **accept** or **cancel**.

Admin guide: [Admin vacation](../admin/VACACIONES.md).

---

## Tips

- Request well in advance.
- Check your **schedule** after approval in case shifts still need to be removed.
