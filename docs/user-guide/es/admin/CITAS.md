# Citas (admin)

**Ruta:** `/admin/appointments`  
**Módulo requerido:** `appointments`

---

## Qué puedes hacer

- Ver solicitudes de **cita** de los trabajadores.
- **Proponer franjas horarias** disponibles.
- Confirmar o cancelar citas.
- Gestionar el calendario de citas de la empresa.

---

## Flujo típico

1. Trabajador solicita cita desde la app → [Citas trabajador](../worker/CITAS.md).
2. Admin recibe la solicitud.
3. Admin propone uno o varios huecos.
4. Trabajador acepta una franja o cancela.

---

## Consejos

- Responde con franjas realistas para reducir idas y vueltas.
- Usa notas internas si la pantalla lo permite para contexto (revisión médica, reunión, etc.).
