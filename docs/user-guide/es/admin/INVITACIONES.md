# Invitaciones (admin)

**Ruta:** `/admin/invitations`

---

## Para qué sirve

Permite que un **nuevo trabajador** (u otro rol de empresa) cree su cuenta sin que el admin escriba la contraseña por él.

---

## Crear una invitación

1. Ve a **Invitaciones**.
2. Pulsa crear / nueva invitación.
3. Indica el **email** del destinatario (y datos que pida el formulario).
4. Guarda y **copia el enlace** de invitación o envíalo por correo.

---

## Qué hace el invitado

1. Abre el enlace (`/invitation/accept`).
2. Completa el formulario de registro (nombre, contraseña, etc.).
3. Inicia sesión con sus credenciales.
4. En móvil: instala la app GoRuiz e inicia sesión con el mismo email.

Guía: [Inicio en la app](../worker/INICIO.md).

---

## Problemas frecuentes

| Problema | Solución |
|----------|----------|
| Enlace caducado o usado | Crear nueva invitación |
| «Email ya registrado» | El usuario ya existe; usar recuperación de acceso o revisar en Usuarios |
| No llega el correo | Comprobar spam; reenviar enlace manualmente |
