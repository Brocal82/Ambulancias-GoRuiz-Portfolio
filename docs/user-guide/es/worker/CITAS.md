# Citas (trabajador)

**Sección:** Citas  
**Módulo:** `appointments`

---

## Solicitar una cita

1. Abre **Citas**.
2. Crea una nueva solicitud con el motivo o tipo que indique el formulario.
3. Espera respuesta del administrador.

---

## Respuesta

El admin puede **proponerte franjas horarias**. Elige la que te convenga o cancela si ya no la necesitas.

Guía admin: [Citas admin](../admin/CITAS.md).

---

## Recordatorios

Si recibes notificación push con enlace a citas, pulsa para abrir la sección correspondiente.
