# Nóminas (trabajador)

**Acceso:** desde Inicio o sección Nóminas (web `/worker/payroll`)  
**Módulo:** `payroll`

---

## Qué ves

- Listado de **tus nóminas** por mes/año que el administrador haya subido y asignado a tu usuario.
- Solo documentos **activos** (no versiones invalidadas).

---

## Abrir una nómina

1. Selecciona el periodo.
2. Pulsa para **abrir** el PDF.
3. La app descarga el archivo de forma segura y te permite verlo o compartirlo según el sistema.

---

## Si falta una nómina

Contacta con administración. Puede estar pendiente de subida, sin asignar o con error de emparejamiento.

Guía admin: [Nóminas admin](../admin/NOMINAS.md).
