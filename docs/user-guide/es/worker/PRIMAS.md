# Primas (trabajador)

**Acceso:** desde Inicio o sección Primas  
**Módulo:** `praemien`

---

## Qué ves

- Resumen de **primas** de meses ya **confirmadas** o **pagadas** por tu empresa.
- En modo automático, dependen de las jornadas que hayas registrado y el admin haya revisado.
- En modo manual, el admin introduce los importes.

Guía admin: [Primas admin](../admin/PRIMAS.md).

---

## Si no aparece una prima

- El mes puede seguir en borrador.
- Las jornadas pueden no estar revisadas aún.
- El módulo puede no estar activo.

Pregunta a tu administrador con el mes concreto.
