# Manual del trabajador

Uso de la **app móvil GoRuiz** (recomendado) y, si tu empresa lo permite, rutas web bajo `/worker`.

Solo usuarios con rol **trabajador** (`worker`) deben usar este manual. Si eres administrador, consulta también el [manual de admin](../admin/README.md).

## Módulos que no ves

Si falta una pestaña (por ejemplo Jornada o Vacaciones), tu empresa puede no tener ese módulo activo. Pregunta a tu administrador.

---

## Ayuda desde administración

Tu responsable usa las guías de admin para aprobar vacaciones, subir nóminas, etc. Puedes indicarle el [manual admin](../admin/README.md) si necesita el procedimiento.
