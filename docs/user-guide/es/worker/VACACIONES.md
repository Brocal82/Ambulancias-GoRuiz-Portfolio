# Vacaciones (trabajador)

**Sección:** Vacaciones (pestaña o acceso desde Inicio)  
**Módulo:** `vacation`

---

## Solicitar vacaciones

1. Abre **Vacaciones**.
2. Elige **fecha de inicio** y **fecha de fin**.
3. Envía la solicitud.
4. Estado **pendiente** hasta que el admin responda.

---

## Respuesta del administrador

Puede ocurrir:

- **Aceptada** — fechas aprobadas.
- **Rechazada** — consulta el motivo con tu responsable.
- **Opción alternativa** — el admin propone otras fechas; tú **aceptas** o **cancelas**.

Guía admin: [Vacaciones admin](../admin/VACACIONES.md).

---

## Consejos

- Solicita con antelación.
- Revisa la **agenda** tras la aprobación por si hubiera turnos que el admin deba quitar.
